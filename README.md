# 🐍 Python Programming, Data Science & Web Development Foundations

Welcome to my comprehensive practice repository covering foundational Python programming, numerical computing with **NumPy**, desktop UI development, and full-stack web application development using **Flask** and **SQLite**.

This repository documents my structured learning path, hands-on bootcamp modules, and mini-projects built during my AI and Software Engineering specialization.

---

## 📂 Repository Architecture & Key Modules

The codebase is organized into multi-tier modules ranging from core logic to full-stack web applications:

### 🎓 AI Bootcamp Modules
* 📁 **`modul_1/` (Core Python & Logic):** Daily algorithmic exercises, string/data manipulations, module creation (`math_operations.py`), and file I/O operations.
* 📁 **`modul_2/` (Numerical Computing with NumPy):** Array operations, matrix manipulations, indexing, slicing, and scientific computations (`day1_NumpyBasics.py` to `day7_ex.py`).
* 📁 **`modul_3/` & `modul_4/` (Data Structures & Applied Logic):** Advanced data manipulation exercises, mini-projects, and computational logic building.
* 📁 **`modul_5/` (Interactive Tools):** Console-based interactive applications including `#Simple Calculator.py` and `basic_math_quiz.py`.

---

### 🌐 Web Development with Python (Flask)
Located under `AI bootcamp/web development with python/`:

1. 📝 **Personal Blog Application (`personal_blog/`)**: 
   * Dynamic blog interface rendered using Flask templates, Jinja2 layout inheritance (`layout.html`), and custom CSS styling.
2. 📬 **Contact Form App (`Contact Form App Forms & User Input/`)**: 
   * Web-based user contact portal handling HTML form submissions, POST request processing, and dynamic response rendering.
3. 🔐 **User Registration App with Database Integration (`User Registration App-Database Integration/`)**: 
   * Full-stack user registration pipeline integrated with an active **SQLite** database (`users.db`) for user persistence.

---

### 🖥️ Desktop Applications & GUI
* 🖥️ **Desktop Task Manager (`day7_task_manager.py`)**: Console/modular task management utility.
* 🎨 **Tkinter GUI Applications (`simple_GUI_app.py`, `tkinterBasic.py`)**: Desktop graphical user interface elements built with Python's standard `tkinter` library.
